**设置页改为二级菜单。** 没有新能力，纯粹把堆积了 8 个区块的设置页拆开。原因很简单：想关掉代码执行，得先划过工作区、一整屏模型参数、联网搜索才能看到那个开关。

---

## 为什么要动

到 1.10.0 为止，设置页是一个 `Column` + `verticalScroll`，里面平铺了：

| # | 区块 |
|---|---|
| 1 | 工作区 |
| 2 | 模型档案（地址 / Key / 模型 / 温度 / 视觉 / 思考） |
| 3 | 联网搜索 |
| 4 | 代码执行 |
| 5 | 本机命令 |
| 6 | 长期记忆 |
| 7 | 上下文压缩 |
| 8 | 系统提示词 |

问题不是「长」—— 手机屏幕本来就只能显示一屏。问题是**找不到**：用户带着一个明确目标进来（关掉某个开关、改个 Key），却要先划过七个跟他无关的区块。而且每加一个功能，所有东西都往下沉一截。

---

## 现在长什么样

首页只剩目录，六个入口，一项一行，每行一句状态摘要。

```
设置
├─ 工作区  Documents/PhoClaw            [更换目录]
│
├─ 对话与模型
│   ├─ 模型与连接    deepseek-reasoner · api.deepseek.com
│   ├─ 上下文压缩    自动压缩 · 预算 32000 token
│   └─ 系统提示词    自动生成 · 跟随工具表更新
│
├─ 能力与数据
│   ├─ 工具与权限    联网搜索 · 代码执行
│   └─ 长期记忆      12 条 · 注入每轮对话
│
└─ 关于            v1.11.0 · 数据去向一览

凭据使用 Android Keystore 加密后存储，不会明文保存。
```

摘要是有信息量的 —— **不进二级页也能知道系统状态**：现在连的是哪个后端（没填 Key 会变红）、压缩开没开、提示词是自动生成还是已经固定、开了哪几个工具、记忆多少条。

这是这次改版比「拆页面」更重要的部分：如果首页只写「模型设置」「高级选项」这类词，用户还是得逐个点进去确认，等于把一次长滚动换成了六次跳转。

### 六个二级页

| 页面 | 内容 |
|---|---|
| 模型与连接 | 档案切换 / 新建 / 删除，名称、Key、Base URL、模型名、温度、视觉开关、思考开关 |
| 上下文压缩 | 自动压缩开关，预算与「保留最近」，预算属于当前档案 |
| 系统提示词 | 完整文本，保存 / 恢复自动生成 |
| 工具与权限 | 联网搜索、代码执行、本机命令（鸿蒙隐藏），各自的隐私警告就在开关旁边 |
| 长期记忆 | 注入开关、内容编辑器、条数与字数、清空（二次确认） |
| 关于 | 版本、**数据去向一览**、凭据存储方式、已知限制 |

## 三个刻意的取舍

### 「工具与权限」把三个开关放一页

联网搜索、代码执行、本机命令原本散在页面各处，中间隔着模型参数。它们性质相同 —— 都是**扩大 AI 的能力边界**，其中两个涉及数据外发，一个涉及设备执行权。

放一页之后，用户想「收紧权限」时有一个明确的去处，而不是凭记忆去三个位置找。每个开关旁边紧跟着自己的警告：代码会去 wandbox.org、命令会在你自己的设备上真删东西。

### 「保存」移到底部固定栏

原来保存按钮夹在页面中间（模型名字段下方）。用户在下面的「视觉开关」附近改完，得往上翻才能保存。

现在每个二级页有自己的底部操作栏，滚到哪都看得见。代价是内容区少了一条底部空间 —— 值得。

### 离开页面自动落盘，但清空不算

拆成二级页之后有个新问题：**切页 = 整棵子树被销毁**。用户填好 API Key，顺手点返回，回来发现 Key 没了 —— 这会被当成「保存失败」。

所以模型页和记忆页在 `onDispose` 里自动保存。两个细节：

- 用 `rememberUpdatedState` 读最新值。直接闭包捕获会拿到第一次组合时的快照，等于保存了「进页面时的原始值」，比不保存更糟。
- 记忆页只在**文本非空且真的改过**时才写。清空必须走带确认的按钮 —— 那是几个月的偏好积累，不能因为一次误删光标就抹掉。

---

## 顺手修的

- 记忆页和上下文页的说明文字里有 `**每一轮**` 这种 Markdown 星号。`Text` 不渲染 Markdown，界面上原样显示成了星号，已去掉。
- 工具开关的状态会写进系统提示词（`run` / `shell` 能不能用）。拆页之后两个页面不再共享一个 `systemPrompt` 变量，改由 `CredentialStore` 的缓存失效机制保证下次进来拿到新内容 —— 原来靠手工回写，是拆页时最容易漏的一处同步。
- 说明文字的字号统一成一套：正文 14/15、小标题 13、说明 11sp。原来 11 和 12 混着用。

---

## 升级注意

**没有数据迁移**。这次只改了界面结构，所有配置的存储格式、Key 的位置、档案的迁移逻辑全部没动。装上去就是这样，不用重新填任何东西。

唯一的可见变化是入口位置变了 —— 如果找不到某样东西，先看它在「首选与模型 / 能力与数据 / 关于」哪一组。

---

## 已知限制

- 二级页切换用的是 `AnimatedContent`，快速连点两次导航会有短暂的重叠帧。不影响功能，也没打算为此引入 navigation-compose 的一整套依赖。
- 「关于」页的版本号从 `PackageManager` 读，debug 构建带 `.debug` 后缀的包名也在读自己 —— 显示正常。
- 数据去向清单是**手写维护**的静态文本。以后新增外部服务时必须记得同步，不然这一页就会开始说谎。
